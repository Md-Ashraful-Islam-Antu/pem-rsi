📅 Gantt Chart ★★☆☆
A Gantt chart is a bar chart showing project activities plotted against time. Each activity is a horizontal bar; the bar's length = activity duration.

🔑 Critical Path Method ★★★★ — 20 marks numerical
Most important numerical topic in this course. Master the forward pass, backward pass, and critical path identification.

Key Terms

TermMeaningFormula
ESEarliest Start timeMax(EF of all predecessors)
EFEarliest Finish timeES + Duration
LSLatest Start timeLF − Duration
LFLatest Finish timeMin(LS of all successors)
Slack/FloatAllowable delay without delaying projectLS − ES or LF − EF
Critical PathLongest path; activities with Slack = 0Longest path through network

Forward Pass (Calculate ES/EF)

Start from the left. For each activity: ES = max(EF of all predecessors). EF = ES + Duration. For the starting node, ES = 0.

Backward Pass (Calculate LS/LF)

Start from the right. For the last activity: LF = Project Duration. LS = LF − Duration. For each other activity: LF = min(LS of all successors).

Slack Calculation

Slack / Total Float
Slack = LS − ES = LF − EF
Critical activities: Slack = 0. Non-critical: Slack > 0 (can be delayed without delaying project).
🎲 PERT — Probabilistic Scheduling ★★★☆
PERT uses three time estimates for each activity to account for uncertainty. This is essential for R&D and new product development where exact durations are unknown.
PERT Expected Time Formula
te = (O + 4M + P) / 6
O = Optimistic time (best case)
M = Most likely time (mode)
P = Pessimistic time (worst case)
The factor 4 on M reflects that the most likely estimate is the most probable outcome (beta distribution approximation).
Variance of Activity Duration
σ² = [(P − O) / 6]²
The larger the range (P−O), the more uncertain the activity. Variance is used to calculate overall project risk.
ActivityOMPteσ²
A246(2+16+6)/6 = 4.0[(6−2)/6]² = 0.44
B138(1+12+8)/6 = 3.5[(8−1)/6]² = 1.36
C357(3+20+7)/6 = 5.0[(7−3)/6]² = 0.44
The critical path expected duration = Σ te along critical path. The variance of the project = Σ σ² of critical path activities. These allow probability calculations about meeting a deadline.
