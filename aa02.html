Functional, Dedicated, Matrix

Chapter 2 covers the three main ways organizations can be structured for project management. The key debate is between keeping projects inside functional departments vs. creating dedicated project teams vs. using a matrix arrangement that blends both.

Exam focus: Matrix organization is the most asked topic. Know advantages, disadvantages, and the three sub-types (weak/balanced/strong). The comparison table between all three structures is essential.
🏛️ Functional Organization ★★★☆
In a functional organization, projects are run within existing functional departments (Engineering, Marketing, Finance, etc.). The functional manager has authority over the project within their department.
✅ Advantages❌ Disadvantages
No duplication — experts shared across projectsClient not the focus; customer is secondary
Strong technical depth in each functionNo single owner accountable for whole project
Career path clear for specialistsSlow response to changes (bureaucratic)
Easy knowledge sharing within departmentMotivation of project staff is low
Flexible use of human resourcesCross-functional coordination is poor
🚀 Dedicated / Pure Project Organization ★★★☆
In a dedicated (pure) project structure, a self-contained project team is created. The Project Manager has full authority and all needed staff are assigned exclusively to the project.
✅ Advantages❌ Disadvantages
PM has full authority — fast decisionsDuplication of resources (costly)
Clear accountability for project successExperts isolated — miss functional expertise
Team loyalty to project is strongWhat happens to team after project ends?
Fast response to problems and changesInconsistency in technical approaches
Client has one point of contactMay conflict with parent organization policies
⚙️ Matrix Organization ★★★★ — Most Frequent
Highest exam frequency for this chapter. Know the structure, all advantages and disadvantages, and the three types of matrix.
A matrix organization overlays project management on top of a functional structure. Staff report to both their functional manager AND the project manager simultaneously — a "two-boss" system.
